# Observability and reliability

Adopt OpenTelemetry-compatible traces, metrics and structured logs. Use correlation IDs across API, workers and provider webhooks. Never log secrets, raw identity evidence or payment credentials.

Define indicators before SLOs: availability, latency, error rate, queue age, webhook delay, reconciliation drift and critical journey success. Establish on-call ownership, incident severity, communication templates and post-incident reviews.

Backups must be encrypted, access-controlled and restoration-tested. Define RPO/RTO per data class and capability. A successful backup job without a tested restore is insufficient evidence.
