# Engines and capabilities

| Engine                  | Primary responsibility                                 |
| ----------------------- | ------------------------------------------------------ |
| Identity                | Accounts, authentication, recovery and identity claims |
| Professional Capability | Skills, experience, portfolio and work evidence        |
| Opportunity             | Work, projects, tenders and partnerships               |
| Service Marketplace     | Service listings, packages and contracting             |
| Vector Intelligence     | Search, matching and explanation                       |
| Trust                   | Reviews, evidence, moderation and disputes             |
| Transaction/Financial   | Payments, journal, invoices and refunds                |
| Project                 | Milestones, deliverables and acceptance                |
| Communication           | Messaging, notifications and preferences               |
| Learning                | Learning content and pathways                          |
| Certification           | Issuer and credential lifecycle                        |
| Governance              | Policies, consent, audit and appeals                   |
| Globalization           | Locale, currency, time zone and jurisdiction           |
| Opportunity Equity      | Fair exposure and inclusion programs                   |
| Business Intelligence   | Privacy-aware metrics and reporting                    |

Each engine needs an owner, glossary, data classification, authorization model, threat review, API/event contract, tests and operational SLO before production release.
