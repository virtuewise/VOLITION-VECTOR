# Privacy by design

- Establish purpose and lawful basis per processing activity.
- Collect only necessary attributes; separate public profile data from verification evidence.
- Set retention schedules and automate deletion/anonymization where legally permitted.
- Support access, correction, export, objection, restriction and deletion workflows as applicable.
- Document processors, subprocessors, transfers and security measures.
- Use privacy-preserving analytics and avoid sensitive-trait inference.
- Assess DPIA requirements before high-risk processing, profiling or new AI use.
- Ensure consent is granular, informed and revocable; do not use it as a substitute for another lawful basis.
- Design meaningful human review and contestability for consequential automated decisions.
