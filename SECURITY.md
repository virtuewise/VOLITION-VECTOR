# Security Policy

Do not disclose vulnerabilities in public issues. Use GitHub private vulnerability reporting for this repository until a monitored security contact is published. Include impact, affected versions, reproduction steps and a safe proof of concept. Do not access or modify another person's data.

Baseline: least privilege, secure defaults, secrets outside source control, dependency/container/secret/static analysis, supported runtimes, auditable privileged actions, incident response and tested backup restoration. This policy is not a certification or proof of application security.
